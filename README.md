# Pokédex Kanto — Criado por Georgederick

Pokédex interativa dos 151 Pokémon de Kanto, feita com HTML, CSS e JavaScript puro, consumindo a [PokéAPI](https://pokeapi.co/api/v2/).

## Recursos
- Tela de inicialização animada e interface de Pokédex em HTML/CSS
- Catálogo com busca (nome ou número), filtro por tipo, ordenação e paginação
- Ficha com estatísticas animadas, habilidades, altura, peso, experiência e habitat
- Alternância Normal/Shiny com comparação
- Linha evolutiva com ramificações, método de evolução e navegação por clique
- Aba de curiosidades (entradas da Pokédex, grupos de ovos, taxa de captura)
- Favoritos, coleção com porcentagem, comparador de dois Pokémon
- Cache e dados salvos no LocalStorage, skeleton loading, efeitos sonoros com liga/desliga

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub e envie todos os arquivos desta pasta.
2. Vá em **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`.
4. Acesse `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Não há build nem dependências; todos os caminhos são relativos.

## Dados e idioma
